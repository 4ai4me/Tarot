# 세 장의 타로

질문 영역을 고르고 카드 세 장을 뽑아 읽는 개인용 타로 웹페이지입니다. 서버, 로그인, 저장이 없는 정적 사이트라 GitHub Pages에 그대로 올려 씁니다.

## 쓰는 법

1. 마음속 질문을 적습니다 (선택, 어디에도 저장되지 않습니다).
2. 나이(숫자, 1~120)와 성별(여성/남성/선택 안 함)을 넣습니다 (선택, 저장되지 않습니다). 결과 제목과 총평 첫머리에만 쓰이고 카드 해석 문장은 바뀌지 않습니다.
3. 볼 영역을 고릅니다: 연애 흐름, 상대의 속마음, 취업, 성적, 발표·사업, 재물, 이동·여행, 친구 관계, 새학기, 진로, 가족.
4. 카드 자리를 고릅니다: 과거/현재/미래, 상황/조언/결과, 현재/장애/결과, 나/너/우리.
5. "카드 세 장 뽑기"를 누르면 78장 중 서로 다른 3장이 나옵니다. 카드별 해석 아래에 세 장을 하나의 이야기로 이은 총평 **"그래서 결말은?"**이 나옵니다.

## 해석 방식

- 해석문은 강의 교안을 바탕으로 새로 쓴 문장입니다. 교안에 없는 영역(특히 마이너 카드의 취업·성적, 코트 카드 대부분)은 원소·숫자·계급 원리로 추론해 썼고, 목록은 [docs/해석_검토목록.md](docs/해석_검토목록.md)에 있습니다.
- 친구 관계·새학기·진로·가족 4개 영역은 교안에 없어 나중에 추가한 영역입니다. 78장 모두 추론으로 썼고 전부 검토 목록에 올라 있습니다.
- 역방향은 쓰지 않습니다. 대신 이웃한 카드의 원소 관계로 힘의 강약을 봅니다 (골든 던의 원소 위계).
  - 같은 원소, 불–공기, 물–흙: 서로 북돋움
  - 불–물, 공기–흙: 서로 약하게 함
  - 나머지: 중립
  - 메이저 카드는 원소가 없어 중립입니다.
  - 가운데 카드가 주인공이고, 양옆 카드가 그 힘을 키우거나 줄입니다. 양옆 카드가 서로 맞서면 둘이 상쇄되어 가운데 카드가 그대로 드러납니다.
- 총평 "그래서 결말은?"은 교안의 카드 연결법을 따릅니다.
  - 이웃 카드가 서로 북돋우면 "그래서", 부딪치면 "하지만", 중립이거나 메이저가 끼면 "그리고"로 잇습니다.
  - 마지막 자리 카드의 해석을 결말로 보여 주고, 가운데 카드의 강약에 따라 결말을 얼마나 뚜렷하게 볼지 덧붙입니다.
  - 가운데나 마지막이 메이저 카드면 실제 일보다 마음가짐 쪽으로 읽으라고 안내합니다 (교안: 메이저는 주관, 마이너는 객관).
  - 좋다·나쁘다를 딱 잘라 판정하지는 않습니다.

## 카드 그림

1909년 라이더-웨이트-스미스 덱 원본(퍼블릭 도메인)을 위키미디어 공용에서 바로 불러옵니다. 그래서 그림은 보는 사람의 브라우저가 위키미디어에 직접 요청합니다. 그림을 못 불러오면 숫자·문양·이름을 그린 카드 면이 대신 보입니다.

## GitHub Pages 켜기

1. 저장소 **Settings → Pages**
2. **Build and deployment**의 Source를 **Deploy from a branch**로
3. Branch를 **main**, 폴더를 **/ (root)**로 두고 **Save**
4. 몇 분 뒤 `https://4ai4me.github.io/Tarot/`에서 열립니다.

GitHub 무료 계정에서는 저장소와 사이트가 모두 공개됩니다. 주소를 아는 사람은 누구나 볼 수 있습니다.

## 파일 구조

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 |
| `css/style.css` | 디자인 |
| `js/app.js` | 화면 동작 |
| `js/reading.js` | 뽑기, 원소 관계, 가운데 카드 판정, 총평 문장 만들기, 나이 검사, 그림 주소 (화면과 분리된 로직) |
| `js/data/*.js` | 카드 78장의 키워드·요약·11개 영역 해석 |
| `tests/` | 자동 테스트 |
| `tools/review-list.js` | 추론 해석 검토 목록 만들기 |
| `AGENTS.md`, `docs/VIBE_REFERENCE.md` | 작업 규칙 (AI 코딩 도구용) |
| `log.md` | 작업 기록 |
| `TEST_PLAN.md` | 손으로 확인할 목록 |

## 해석문 고치기

`js/data/` 안에서 카드 id(예: `cups_queen`)를 찾아 `areas`의 문장을 바꾸면 됩니다. 추론으로 쓴 영역을 확인했다면 그 카드의 `inferred` 목록에서 해당 영역 이름을 지우세요. 고친 뒤 아래를 실행하면 빠진 문장이 없는지 검사합니다.

## 개발

```
node --test                                         # 자동 테스트 (Node 18 이상, 외부 패키지 없음)
node tools/review-list.js > docs/해석_검토목록.md   # 검토 목록 다시 만들기
```

`index.html`은 빌드 없이 파일을 더블클릭해도 열립니다.
