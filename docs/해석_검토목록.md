# 해석 검토 목록 (교안 외 추론)

총 1291개 문장

교안에 해당 영역의 해석이 없어 원소·숫자·계급 원리로 추론해 쓴 문장입니다. 학교급별 친구 해석, 그림 속 상징, 지금 해 볼 일도 모두 추론으로 쓴 문장입니다.
고칠 문장은 `js/data/` 안의 같은 카드·영역을 바꾸면 되고, 확인을 마친 영역은 그 카드의 `inferred` 목록에서 지우면 됩니다. 상징·학교급·해 볼 일은 확인 표시 없이 이 목록에서 체크만 하면 됩니다.
이 파일은 `node tools/review-list.js > docs/해석_검토목록.md`로 다시 만들 수 있습니다.

## 바보 (The Fool)
- [ ] **친구 관계**: 함께 있으면 즐겁고 가볍게 어울린다. 깊은 속얘기까지 나누는 사이가 되려면 시간이 더 필요하다.
- [ ] **새학기**: 새 환경을 설레는 마음으로 맞는다. 처음엔 신나지만 규칙과 준비물을 놓치기 쉬우니 챙겨야 한다.
- [ ] **진로**: 하고 싶은 것은 많지만 아직 구체적인 계획이 없다. 이것저것 겪어 보며 방향을 찾는 시기다.
- [ ] **가족**: 집안 분위기는 가볍고 자유롭다. 다만 서로의 계획을 잘 모르고 각자 움직이기 쉽다.
- [ ] **짝사랑·고백**: 설레는 마음에 앞뒤 재지 않고 다가가고 싶어진다. 즐거운 분위기는 좋지만 상대의 마음을 먼저 살피는 여유가 필요하다.
- [ ] **외모·자신감**: 남의 눈을 신경 쓰지 않고 내 멋대로 꾸미는 자유로움이 매력이 된다. 가끔은 때와 장소도 함께 생각하자.
- [ ] **요즘 내 마음**: 마음이 가볍고 홀가분하다. 다만 해야 할 일을 미뤄 둔 것이 나중에 걱정으로 돌아오지 않게 챙기자.
- [ ] **용돈·돈 관리**: 사고 싶은 것이 보이면 바로 써 버리기 쉽다. 용돈을 받으면 일부를 먼저 떼어 두자.
- [ ] **초등 친구**: 처음 보는 친구와도 금방 놀이를 시작한다. 장난이 지나치면 친구가 속상할 수 있으니 멈출 때를 알자.
- [ ] **중등 친구**: 여러 무리와 가볍게 두루 어울린다. 깊이 믿을 친구를 정하는 데는 시간이 더 걸린다.
- [ ] **고등 친구**: 부담 없이 웃고 떠들 친구가 있어 숨통이 트인다. 진로 고민까지 나눌 사이가 되려면 시간이 필요하다.
- [ ] **그림 속 상징**: 낭떠러지: 아직 보지 못한 위험
- [ ] **그림 속 상징**: 흰 장미: 꾸밈없는 순수한 마음
- [ ] **지금 해 볼 일**: 하고 싶은 일을 하나 정해 오늘 바로 가볍게 시작해 보세요. 준비물만은 꼭 챙기고요.

## 마법사 (The Magician)
- [ ] **친구 관계**: 내가 먼저 다가가 관계를 이끈다. 말솜씨와 재치로 친구들 사이의 분위기를 만든다.
- [ ] **새학기**: 준비가 되어 있어 새 반에 빠르게 자리 잡는다. 첫인상에서 내 능력과 매력이 잘 드러난다.
- [ ] **진로**: 하고 싶은 일에 필요한 재능과 도구를 이미 갖췄다. 스스로 길을 만들어 갈 수 있다.
- [ ] **가족**: 집안 일이나 가족 문제를 내가 주도해 풀어 간다. 내 말이 가족에게 잘 통한다.
- [ ] **짝사랑·고백**: 내가 먼저 말을 걸면 대화가 자연스럽게 풀린다. 내 장점을 보여 줄 기회를 스스로 만들 수 있다.
- [ ] **외모·자신감**: 내가 가진 것을 잘 살리는 법을 안다. 말투와 표정에서 자신감이 드러나 실제보다 더 빛나 보인다.
- [ ] **요즘 내 마음**: 할 수 있다는 느낌이 차오른다. 이 기운이 있을 때 미뤄 둔 일을 하나 끝내 보자.
- [ ] **용돈·돈 관리**: 가진 돈으로 할 수 있는 것을 똑똑하게 계획한다. 필요하다면 중고 거래나 작은 아르바이트로 돈을 만들 방법도 찾는다.
- [ ] **초등 친구**: 재미있는 놀이를 먼저 제안해 친구들을 모은다. 친구 생각도 물어보면 더 오래 함께 논다.
- [ ] **중등 친구**: 말솜씨로 단톡방과 교실 분위기를 이끈다. 재치가 누군가를 놀리는 말이 되지 않게 조심하자.
- [ ] **고등 친구**: 모둠 활동이나 동아리에서 능력을 보여 주며 친구가 생긴다. 서로에게 도움이 되는 사이로 자란다.
- [ ] **그림 속 상징**: 책상 위 네 도구: 필요한 것이 이미 다 갖춰짐
- [ ] **그림 속 상징**: 머리 위 무한대 표시: 끝없이 펼칠 수 있는 능력
- [ ] **지금 해 볼 일**: 이미 가진 것(시간, 재능, 도구)을 적어 보고 그중 하나를 오늘 써 보세요.

## 고위 여사제 (The High Priestess)
- [ ] **친구 관계**: 겉으로는 잔잔하지만 속마음을 다 털어놓지 않는다. 서로 말하지 않은 것이 있어 거리가 남는다.
- [ ] **새학기**: 조용히 지켜보며 분위기를 파악한다. 먼저 나서지 않아 친해지는 데 시간이 걸린다.
- [ ] **진로**: 마음속으로만 정해 둔 방향이 있다. 공부와 자료 조사로 차분히 기준을 세우는 시기다.
- [ ] **가족**: 큰 일은 없지만 서로 속마음을 말하지 않는다. 가족에게 꺼내지 못한 고민이 있을 수 있다.
- [ ] **짝사랑·고백**: 마음을 꼭 숨기고 조용히 지켜본다. 상대도 무언가 말하지 않은 것이 있어 아직 서로를 잘 모른다.
- [ ] **외모·자신감**: 화려하기보다 단정하고 차분한 분위기가 매력이다. 굳이 꾸미지 않아도 나만의 분위기가 있다.
- [ ] **요즘 내 마음**: 겉으로는 잔잔하지만 속에 담아 둔 생각이 많다. 일기나 메모로 마음을 꺼내 보면 정리가 된다.
- [ ] **용돈·돈 관리**: 조용히 아끼며 모은다. 어디에 얼마를 썼는지 기록해 두면 돈의 흐름이 더 잘 보인다.
- [ ] **초등 친구**: 친구들과 잘 지내지만 속상한 일은 말하지 않고 참는다. 서운한 일이 있으면 선생님이나 부모님께 이야기하자.
- [ ] **중등 친구**: 무리에 있어도 내 이야기는 잘 하지 않는다. 비밀을 지켜 주는 친구로 믿음을 얻는다.
- [ ] **고등 친구**: 조용히 곁을 지키는 친구다. 고민을 털어놓으면 친구도 더 가까이 다가온다.
- [ ] **그림 속 상징**: 검은 기둥과 흰 기둥: 어느 쪽에도 치우치지 않는 중립
- [ ] **그림 속 상징**: 두루마리: 아직 드러나지 않은 지식과 비밀
- [ ] **지금 해 볼 일**: 마음속에 담아 둔 생각을 세 줄로 적어 보세요. 말하지 않아도 정리가 됩니다.

## 여황제 (The Empress)
- [ ] **친구 관계**: 친구들이 나를 좋아하고 챙겨 준다. 주변에 사람이 모이고 넉넉한 마음을 주고받는다.
- [ ] **새학기**: 새 반에서 호감을 얻고 도움을 받는다. 편안한 분위기 속에서 자연스럽게 어울린다.
- [ ] **진로**: 주변의 지지와 도움 속에서 원하는 방향으로 자란다. 사람을 돌보거나 아름다움을 다루는 일과도 잘 맞는다.
- [ ] **가족**: 가족에게 사랑받고 보살핌을 받는다. 집안 분위기가 넉넉하고 따뜻하다.
- [ ] **짝사랑·고백**: 상대가 나를 편안하고 좋게 느낀다. 다정하게 챙겨 주는 마음이 자연스럽게 전해진다.
- [ ] **외모·자신감**: 편안하고 따뜻한 분위기가 가장 큰 매력이다. 나를 아끼고 돌보는 시간이 겉모습에도 드러난다.
- [ ] **요즘 내 마음**: 마음이 넉넉하고 여유롭다. 좋아하는 것을 즐기며 나를 잘 돌보는 시기다.
- [ ] **용돈·돈 관리**: 주변에서 용돈이나 선물이 들어온다. 넉넉할 때 다 쓰지 말고 일부를 남겨 두자.
- [ ] **초등 친구**: 친구들이 나와 놀고 싶어 한다. 간식이나 장난감을 나눠 쓰며 사이가 더 좋아진다.
- [ ] **중등 친구**: 친구들이 편하게 기대는 사람이 된다. 다 챙기려다 지치지 않게 나도 돌보자.
- [ ] **고등 친구**: 힘든 시기에 서로 챙겨 주는 따뜻한 친구들이 곁에 있다. 고마움을 말로 표현하면 사이가 더 단단해진다.
- [ ] **그림 속 상징**: 익은 밀밭: 노력의 결실과 풍요
- [ ] **그림 속 상징**: 별 열두 개 왕관: 사랑받고 인정받음
- [ ] **지금 해 볼 일**: 오늘은 나를 위한 작은 선물(좋아하는 음식, 휴식)을 하나 준비해 보세요.

## 황제 (The Emperor)
- [ ] **친구 관계**: 관계가 흔들림 없이 이어진다. 다만 내가 주도권을 쥐려 하면 친구가 답답해할 수 있다.
- [ ] **새학기**: 규칙과 질서를 빨리 익혀 안정적으로 자리 잡는다. 반에서 책임 있는 역할을 맡기 쉽다.
- [ ] **진로**: 목표를 정하면 끝까지 밀고 가는 힘이 있다. 체계와 책임이 분명한 길과 잘 맞는다.
- [ ] **가족**: 집안의 규칙과 어른의 뜻이 분명하다. 안정적이지만 내 의견을 말하기 어렵게 느낄 수 있다.
- [ ] **짝사랑·고백**: 진지하고 듬직한 모습으로 다가간다. 다만 내 방식만 고집하면 상대가 부담을 느낄 수 있다.
- [ ] **외모·자신감**: 깔끔하고 단정한 차림이 믿음직해 보인다. 바른 자세 하나만으로도 인상이 달라진다.
- [ ] **요즘 내 마음**: 해야 할 일을 내 손으로 정리하고 싶은 마음이 크다. 너무 꽉 쥐면 피곤해지니 쉬는 시간도 계획에 넣자.
- [ ] **용돈·돈 관리**: 규칙을 세워 꼼꼼히 관리한다. 계획대로 지키면 돈이 차곡차곡 모인다.
- [ ] **초등 친구**: 놀이 규칙을 정하고 친구들을 이끈다. 친구 의견도 들어 주면 더 즐겁게 논다.
- [ ] **중등 친구**: 무리 안에서 책임지는 역할을 맡는다. 내 말만 옳다고 하면 친구들이 거리를 둔다.
- [ ] **고등 친구**: 믿고 기댈 수 있는 친구로 여겨진다. 조언보다 들어 주기가 필요한 순간도 있다.
- [ ] **그림 속 상징**: 숫양 머리가 새겨진 돌 왕좌: 굳은 의지와 지도력
- [ ] **그림 속 상징**: 메마른 바위산: 흔들리지 않지만 딱딱한 환경
- [ ] **지금 해 볼 일**: 이번 주에 꼭 지킬 규칙 한 가지만 정하고, 쉬는 시간도 함께 적어 두세요.

## 교황 (The Hierophant)
- [ ] **친구 관계**: 서로 맞춰 가며 무난하게 지낸다. 속마음보다 예의와 관계 유지를 먼저 생각한다.
- [ ] **새학기**: 정해진 규칙을 따르며 무리 없이 적응한다. 선생님이나 선배의 조언이 도움이 된다.
- [ ] **진로**: 믿을 만한 어른이나 선생님의 조언 속에서 길을 정한다. 주어진 조건과 타협하는 부분이 생긴다.
- [ ] **가족**: 가족끼리 서로 맞춰 주며 관계를 지킨다. 집안의 전통이나 기대를 따르게 된다.
- [ ] **짝사랑·고백**: 친구들의 조언을 들으며 조심스럽게 다가간다. 서두르지 않고 예의 있게 다가가면 좋은 인상을 남긴다.
- [ ] **외모·자신감**: 단정하고 무난한 차림이 잘 어울린다. 상황에 맞는 옷차림이 신뢰를 준다.
- [ ] **요즘 내 마음**: 믿을 만한 어른이나 선배에게 이야기하고 싶어진다. 조언을 구하면 마음이 한결 가벼워진다.
- [ ] **용돈·돈 관리**: 부모님이나 선배에게 돈 쓰는 법을 배우기 좋은 때다. 정해진 약속대로 쓰면 탈이 없다.
- [ ] **초등 친구**: 선생님 말씀을 잘 따르며 친구들과 사이좋게 지낸다. 다툼이 생기면 어른에게 도움을 청하면 쉽게 풀린다.
- [ ] **중등 친구**: 무리의 규칙과 분위기에 맞춰 무난하게 지낸다. 내 생각이 다를 때도 예의 있게 말하면 된다.
- [ ] **고등 친구**: 같은 목표를 가진 친구들과 서로 정보를 나누며 지낸다. 형식적인 관계로만 남지 않게 마음도 나누자.
- [ ] **그림 속 상징**: 교차한 두 열쇠: 배움과 지혜로 문을 엶
- [ ] **그림 속 상징**: 무릎 꿇은 두 사람: 가르침을 듣고 따름
- [ ] **지금 해 볼 일**: 믿을 만한 어른이나 선배에게 지금 고민을 한 가지 물어보세요.

## 연인 (The Lovers)
- [ ] **친구 관계**: 마음이 잘 통하는 친구가 생긴다. 솔직하게 이야기하며 서로를 고른 대등한 사이다.
- [ ] **새학기**: 대화가 잘 통하는 짝을 만난다. 새 반에서 좋은 선택과 즐거운 소통이 이어진다.
- [ ] **진로**: 내 마음이 끌리는 길을 스스로 고른다. 괜찮은 선택지가 생겨 결정하는 시기다.
- [ ] **가족**: 가족과 솔직하게 대화가 오간다. 서로의 선택을 존중하는 분위기다.
- [ ] **짝사랑·고백**: 서로 마음이 통하는 느낌을 받는다. 솔직하게 마음을 전하면 좋은 대답을 들을 가능성이 높다.
- [ ] **외모·자신감**: 내 모습을 있는 그대로 좋아해 주는 사람이 있다. 꾸밈보다 솔직한 표정이 더 매력적이다.
- [ ] **요즘 내 마음**: 마음이 잘 통하는 사람과 이야기하며 위로를 받는다. 무언가를 선택해야 한다면 내 마음이 끌리는 쪽을 믿어 보자.
- [ ] **용돈·돈 관리**: 사고 싶은 것 두 가지 사이에서 고민한다. 정말 필요한 것이 무엇인지 솔직하게 따져 보면 답이 나온다.
- [ ] **초등 친구**: 마음이 잘 맞는 단짝이 생긴다. 다른 친구도 함께 놀자고 하면 더 즐겁다.
- [ ] **중등 친구**: 비밀을 나눌 만큼 마음이 통하는 친구가 생긴다. 서로 솔직하게 말해도 사이가 흔들리지 않는다.
- [ ] **고등 친구**: 진로와 고민을 솔직하게 나누는 친구가 생긴다. 졸업 뒤에도 이어질 수 있는 관계다.
- [ ] **그림 속 상징**: 두 사람 위의 천사: 마음을 이어 주는 축복
- [ ] **그림 속 상징**: 뒤쪽의 나무 두 그루: 선택과 그 책임
- [ ] **지금 해 볼 일**: 하고 싶은 말이 있다면 솔직하고 짧게, 오늘 전해 보세요.

## 전차 (The Chariot)
- [ ] **친구 관계**: 친구 사이에 경쟁하거나 밀고 당기는 일이 생긴다. 내가 적극적으로 나서야 관계가 앞으로 간다.
- [ ] **새학기**: 의욕적으로 출발하지만 처음엔 마음이 바쁘고 쉽지 않다. 스스로 움직이면 자리를 잡는다.
- [ ] **진로**: 목표를 향한 승부욕이 강하다. 고민이 있어도 직접 부딪쳐 길을 연다.
- [ ] **가족**: 가족과 의견이 부딪쳐 내 뜻을 밀고 나가게 된다. 서로 다른 방향을 보고 있을 수 있다.
- [ ] **짝사랑·고백**: 마음먹으면 적극적으로 다가간다. 하지만 이기려는 마음이 앞서면 상대가 당황할 수 있다.
- [ ] **외모·자신감**: 목표를 정하고 꾸준히 관리하면 눈에 띄게 달라진다. 남과 비교하기보다 어제의 나와 비교하자.
- [ ] **요즘 내 마음**: 해내고 싶은 마음과 지친 마음이 서로 끌어당긴다. 잠깐 숨을 고르고 한 가지씩 해 나가면 된다.
- [ ] **용돈·돈 관리**: 갖고 싶은 것을 위해 목표를 세우고 밀고 나간다. 충동적으로 쓰고 싶을 때 한 번만 참으면 목표에 닿는다.
- [ ] **초등 친구**: 놀이에서 이기고 싶은 마음이 크다. 져도 웃으며 다시 하자고 하면 친구가 더 늘어난다.
- [ ] **중등 친구**: 친구와 경쟁하거나 기 싸움을 하게 된다. 이기는 것보다 사이를 지키는 것이 더 중요할 때가 있다.
- [ ] **고등 친구**: 성적이나 진학을 두고 친구와 경쟁하게 된다. 경쟁하면서도 서로 응원하는 사이가 될 수 있다.
- [ ] **그림 속 상징**: 검은 스핑크스와 흰 스핑크스: 서로 다른 두 마음
- [ ] **그림 속 상징**: 고삐 없는 전차: 의지만으로 방향을 잡음
- [ ] **지금 해 볼 일**: 이번 주에 꼭 이루고 싶은 목표 하나를 정하고 첫걸음을 오늘 떼어 보세요.

## 힘 (Strength)
- [ ] **친구 관계**: 자주 만나고 연락하며 가까워진다. 한쪽이 참고 맞춰 주는 사이일 수 있다.
- [ ] **새학기**: 처음엔 긴장되지만 꾸준히 버티면 차츰 편해진다. 적응에 시간이 조금 걸린다.
- [ ] **진로**: 당장 길이 열리지는 않지만 꾸준히 하면 결국 원하는 쪽에 다다른다.
- [ ] **가족**: 내가 참고 맞춰 주는 일이 있다. 부드럽게 대하면 가족 사이가 차츰 나아진다.
- [ ] **짝사랑·고백**: 천천히 다정하게 다가가면 마음이 열린다. 서두르지 말고 꾸준히 친절하게 대하자.
- [ ] **외모·자신감**: 부드러운 말투와 여유 있는 태도가 매력이다. 나를 몰아세우지 말고 다정하게 대하자.
- [ ] **요즘 내 마음**: 힘든 마음을 꾹 참고 견디는 중이다. 참는 것도 용기지만 털어놓는 것도 용기다.
- [ ] **용돈·돈 관리**: 꾹 참고 모으면 시간이 걸려도 원하는 것을 얻는다. 조금씩 꾸준히가 답이다.
- [ ] **초등 친구**: 친구가 화를 내도 차분하게 기다려 준다. 너무 참기만 하지 말고 싫은 것은 싫다고 말하자.
- [ ] **중등 친구**: 친구에게 맞춰 주느라 속앓이를 한다. 부드럽게라도 내 생각을 말해야 관계가 오래간다.
- [ ] **고등 친구**: 예민해진 친구를 이해하고 기다려 준다. 나도 힘들 때는 기대도 된다.
- [ ] **그림 속 상징**: 사자의 입을 다독이는 여인: 힘이 아닌 부드러움으로 다스림
- [ ] **그림 속 상징**: 머리 위 무한대 표시: 끈기 있게 이어지는 마음
- [ ] **지금 해 볼 일**: 서두르던 일을 하나 골라, 오늘은 조금 천천히 해 보세요.

## 은둔자 (The Hermit)
- [ ] **친구 관계**: 혼자 있고 싶은 마음이 커서 연락이 뜸해진다. 먼저 다가가지 않으면 관계가 멀어진다.
- [ ] **새학기**: 새 반에 쉽게 섞이지 못하고 혼자 지내기 쉽다. 마음 맞는 한두 명을 천천히 찾는 것이 낫다.
- [ ] **진로**: 남들과 다른 길을 깊이 파고든다. 다만 혼자 고민만 하면 실제 정보가 부족해진다.
- [ ] **가족**: 가족과 대화가 줄고 각자 방에 머문다. 서로 피곤함을 느끼는 시기다.
- [ ] **짝사랑·고백**: 혼자 마음을 키우며 조용히 생각한다. 지켜보기만 하면 상대는 내 마음을 모른다.
- [ ] **외모·자신감**: 남의 시선보다 내가 좋아하는 것을 찾는 시기다. 유행보다 나에게 맞는 스타일을 고민해 보자.
- [ ] **요즘 내 마음**: 혼자 있고 싶은 마음이 크다. 쉬는 것은 좋지만 너무 오래 혼자 있지는 않게 한 사람과는 연락하자.
- [ ] **용돈·돈 관리**: 돈을 거의 쓰지 않고 지낸다. 아끼는 것은 좋지만 꼭 필요한 데는 써야 한다.
- [ ] **초등 친구**: 혼자 노는 시간이 편하다. 함께 놀고 싶을 때는 먼저 같이 하자고 말해 보자.
- [ ] **중등 친구**: 무리에서 한 발 물러나 지낸다. 마음 맞는 친구 한 명만 있어도 충분하다.
- [ ] **고등 친구**: 공부와 진로 고민에 몰두해 친구와 연락이 뜸해진다. 가끔 안부를 전하면 관계가 이어진다.
- [ ] **그림 속 상징**: 육각별이 든 등불: 스스로 찾는 깨달음
- [ ] **그림 속 상징**: 눈 덮인 산꼭대기: 혼자 오른 높은 생각
- [ ] **지금 해 볼 일**: 혼자만의 조용한 시간을 30분 가지되, 하루에 한 사람과는 꼭 이야기해 보세요.

## 운명의 수레바퀴 (Wheel of Fortune)
- [ ] **친구 관계**: 친구 관계에 흐름의 전환이 온다. 멀던 친구와 가까워지거나 반대로 자연스레 멀어지기도 한다.
- [ ] **새학기**: 새 환경이 기회가 된다. 지난 학기와는 다른 흐름이 시작된다.
- [ ] **진로**: 생각지 못한 계기로 방향이 바뀌거나 길이 열린다. 기회가 오면 붙잡아야 한다.
- [ ] **가족**: 집안에 변화가 생긴다. 이사나 진학 같은 일로 가족의 흐름이 바뀔 수 있다.
- [ ] **짝사랑·고백**: 뜻밖의 계기로 사이가 가까워질 수 있다. 기회가 왔을 때 망설이지 말자.
- [ ] **외모·자신감**: 새로운 스타일을 시도해 보기 좋은 때다. 작은 변화가 분위기를 크게 바꾼다.
- [ ] **요즘 내 마음**: 기분이 오르락내리락한다. 좋은 날도 힘든 날도 지나간다는 것을 기억하자.
- [ ] **용돈·돈 관리**: 뜻밖의 용돈이 생기거나 반대로 예상 못 한 지출이 생긴다. 여유분을 조금 남겨 두자.
- [ ] **초등 친구**: 반이나 짝이 바뀌며 새 친구가 생긴다. 예전 친구와도 계속 인사하자.
- [ ] **중등 친구**: 무리의 분위기가 바뀌어 친한 친구가 달라진다. 흐름에 휩쓸리기보다 마음 맞는 사람을 지키자.
- [ ] **고등 친구**: 반, 학원, 진로가 바뀌며 친구 관계도 달라진다. 자연스러운 변화로 받아들이면 된다.
- [ ] **그림 속 상징**: 돌아가는 수레바퀴: 멈추지 않는 흐름과 변화
- [ ] **그림 속 상징**: 꼭대기의 스핑크스: 변화 속에서도 지키는 중심
- [ ] **지금 해 볼 일**: 평소와 다른 길로 가거나 새로운 것을 하나 시도해 보세요.

## 정의 (Justice)
- [ ] **친구 관계**: 친구 사이에서 옳고 그름을 따지게 된다. 공정하게 대하면 오해가 풀리지만 서운함이 남을 수 있다.
- [ ] **새학기**: 규칙과 기준을 지키며 신중하게 적응한다. 처음 맺는 관계에서 득실을 따지게 된다.
- [ ] **진로**: 조건과 장단점을 꼼꼼히 비교해 결정한다. 감정보다 따져 본 판단이 길을 정한다.
- [ ] **가족**: 가족 사이에 공평함의 문제가 드러난다. 차분하게 따져 이야기하면 정리된다.
- [ ] **짝사랑·고백**: 좋아하는 마음과 현실적인 생각 사이에서 저울질한다. 마음을 전한다면 솔직하고 공정하게 전하자.
- [ ] **외모·자신감**: 깔끔하고 균형 잡힌 차림이 잘 어울린다. 내 장단점을 있는 그대로 보는 눈이 생긴다.
- [ ] **요즘 내 마음**: 옳고 그름을 따지느라 마음이 복잡하다. 남에게 엄격한 만큼 나에게도 너그러워지자.
- [ ] **용돈·돈 관리**: 들어오고 나가는 돈을 정확히 따진다. 친구와 돈 계산은 그때그때 깔끔하게 하자.
- [ ] **초등 친구**: 놀이 순서나 규칙을 공평하게 지키려 한다. 친구가 실수하면 한 번은 봐주자.
- [ ] **중등 친구**: 누가 잘못했는지 따지는 일이 생긴다. 한쪽 말만 듣지 말고 양쪽 이야기를 다 들어 보자.
- [ ] **고등 친구**: 공정하게 대하는 모습으로 신뢰를 얻는다. 다만 감정을 놓치면 서운함이 남는다.
- [ ] **그림 속 상징**: 저울: 공정하게 따져 봄
- [ ] **그림 속 상징**: 곧게 세운 칼: 분명한 결정
- [ ] **지금 해 볼 일**: 고민하던 일의 좋은 점과 걱정되는 점을 나란히 적고 결정해 보세요.

## 매달린 남자 (The Hanged Man)
- [ ] **친구 관계**: 대화가 잘 이어지지 않고 관계가 제자리다. 내가 참고 기다리는 입장이 된다.
- [ ] **새학기**: 적응이 더디고 답답하게 느껴진다. 다른 눈으로 보면 이 시간도 배울 거리가 된다.
- [ ] **진로**: 방향을 정하지 못하고 멈춰 있다. 지금은 생각을 바꿔 보는 시간이 필요하다.
- [ ] **가족**: 가족을 위해 내가 양보하거나 참는 일이 생긴다. 서로 말이 통하지 않아 답답하다.
- [ ] **짝사랑·고백**: 마음은 있지만 지금은 기다리는 것밖에 할 수 없다. 서두르기보다 다른 각도로 상황을 보자.
- [ ] **외모·자신감**: 같은 모습도 보는 시선에 따라 달라 보인다. 단점이라 여긴 것이 다른 사람에겐 매력일 수 있다.
- [ ] **요즘 내 마음**: 아무것도 되지 않는 것처럼 답답하다. 잠깐 멈추는 것이 다음을 위한 준비가 된다.
- [ ] **용돈·돈 관리**: 사고 싶은 것을 당분간 미뤄야 한다. 기다리는 동안 정말 필요한지 다시 생각하게 된다.
- [ ] **초등 친구**: 친구가 놀아 주지 않아 서운하다. 조금 기다리거나 다른 친구에게 함께 놀자고 해 보자.
- [ ] **중등 친구**: 친구 사이에서 혼자 참는 입장이 된다. 오래 참기만 하지 말고 마음을 말할 때를 찾자.
- [ ] **고등 친구**: 바빠서 친구와 시간이 맞지 않는다. 지금은 각자 할 일을 하는 시기로 받아들이자.
- [ ] **그림 속 상징**: 거꾸로 매달린 사람: 세상을 다른 각도로 봄
- [ ] **그림 속 상징**: 머리 뒤 후광: 멈춤 속의 깨달음
- [ ] **지금 해 볼 일**: 답답한 일을 친구 입장이나 1년 뒤의 나의 눈으로 다시 바라보세요.

## 죽음 (Death)
- [ ] **친구 관계**: 한 관계가 분명하게 끝난다. 아프지만 그 자리에서 새 인연이 자란다.
- [ ] **새학기**: 지난 학기의 관계와 습관을 정리하고 완전히 새로 시작한다.
- [ ] **진로**: 지금까지 생각하던 길을 접게 된다. 끝을 받아들이면 다른 방향이 보인다.
- [ ] **가족**: 집안의 한 시기가 마무리된다. 익숙한 방식이 바뀌어 낯설게 느껴질 수 있다.
- [ ] **짝사랑·고백**: 한 마음이 끝나고 새로운 마음이 시작된다. 이어지지 않더라도 다음 인연을 위한 자리가 생긴다.
- [ ] **외모·자신감**: 예전 모습과 작별하고 새롭게 바꾸고 싶어진다. 크게 바꾸기 전에 한 번 더 생각하자.
- [ ] **요즘 내 마음**: 무언가가 끝나 허전하다. 아쉬운 마음을 충분히 느끼고 나면 새 시작이 보인다.
- [ ] **용돈·돈 관리**: 쓸데없이 나가던 돈을 끊기 좋은 때다. 안 쓰는 구독이나 습관을 정리하자.

## 절제 (Temperance)

- [ ] **초등 친구**: 여러 친구와 골고루 사이좋게 지낸다. 친구 둘이 다투면 화해를 도울 수 있다.
- [ ] **중등 친구**: 여러 무리와 두루 잘 지낸다. 한쪽에만 치우치지 않아 다툼에 휘말리지 않는다.
- [ ] **고등 친구**: 적당한 거리에서 서로 존중하는 편안한 관계다. 함께 공부하고 쉬기에 좋은 친구다.

- [ ] **그림 속 상징**: 물과 땅에 한 발씩: 양쪽의 균형
- [ ] **지금 해 볼 일**: 공부(일)와 쉼을 50분과 10분처럼 나눠 오늘 한 번 해 보세요.

## 악마 (The Devil)

- [ ] **그림 속 상징**: 받침대 위의 존재: 나를 붙잡는 욕심
- [ ] **지금 해 볼 일**: 끊고 싶은 습관 하나를 정하고, 오늘 하루만 그것 없이 지내 보세요.

## 탑 (The Tower)

- [ ] **진로**: 세워 둔 계획이 뜻밖의 일로 무너진다. 무리한 목표였는지 다시 살펴야 한다.

## 별 (The Star)

- [ ] **초등 친구**: 친구들이 나와 함께 놀고 싶어 한다. 친절한 행동이 친구들에게 좋은 본보기가 된다.

## 달 (The Moon)
- [ ] **친구 관계**: 오해와 의심이 생긴다. 확인하지 않은 말 때문에 마음이 흔들린다.
- [ ] **새학기**: 낯선 환경이 막연히 불안하다. 걱정보다 실제로 무엇이 어려운지 확인해야 한다.
- [ ] **진로**: 방향이 흐릿하고 확신이 없다. 정보가 부족해 불안만 커지니 직접 알아봐야 한다.
- [ ] **가족**: 가족 사이에 말하지 않은 오해가 쌓인다. 혼자 짐작하지 말고 물어보는 것이 좋다.
- [ ] **짝사랑·고백**: 상대의 마음이 잘 보이지 않아 혼자 상상이 커진다. 확인하지 않은 짐작으로 결론 내리지 말자.
- [ ] **외모·자신감**: 거울 앞에서 괜히 불안해지는 때다. 조명이나 기분에 따라 다르게 보일 뿐 실제 나는 그대로다.
- [ ] **요즘 내 마음**: 이유 없이 불안하고 마음이 뒤숭숭하다. 밤에 걱정이 커진다면 아침에 다시 생각해 보자.
- [ ] **용돈·돈 관리**: 돈이 어디로 나갔는지 흐릿하다. 영수증이나 기록을 확인하면 불안이 줄어든다.
- [ ] **초등 친구**: 친구가 나를 싫어하는 것 같아 걱정된다. 혼자 고민하지 말고 직접 물어보거나 어른에게 이야기하자.
- [ ] **중등 친구**: 단톡방의 말투나 소문 때문에 오해가 생긴다. 확인하지 않은 이야기는 퍼뜨리지 말자.
- [ ] **고등 친구**: 친구의 진심을 몰라 불안하다. 짐작하기보다 직접 대화하는 것이 가장 빠르다.
- [ ] **그림 속 상징**: 달을 보고 우는 개와 늑대: 길들여진 마음과 거친 마음
- [ ] **그림 속 상징**: 물에서 기어 나오는 가재: 떠오르는 무의식의 불안
- [ ] **지금 해 볼 일**: 불안한 생각을 종이에 적고, 사실인 것과 짐작인 것을 나눠 보세요.

## 태양 (The Sun)
- [ ] **친구 관계**: 밝고 즐거운 관계다. 친구들 사이에서 내가 중심이 되고 함께 웃을 일이 많다.
- [ ] **새학기**: 활기차게 시작해 새 반에서 금방 눈에 띈다. 들떠서 실수하지 않도록만 조심하면 된다.
- [ ] **진로**: 하고 싶은 일이 분명하고 자신감이 넘친다. 실력과 운이 함께 따른다.
- [ ] **가족**: 집안 분위기가 밝고 화목하다. 가족이 내 성취를 함께 기뻐한다.
- [ ] **짝사랑·고백**: 밝고 솔직한 모습이 상대에게 좋게 비친다. 함께 웃을 일이 많아진다.
- [ ] **외모·자신감**: 자신감이 얼굴에 드러나 환해 보인다. 밝은 표정이 어떤 꾸밈보다 잘 어울린다.
- [ ] **요즘 내 마음**: 기운이 넘치고 마음이 환하다. 좋은 기분일 때 해야 할 일도 미리 해 두자.
- [ ] **용돈·돈 관리**: 기분 좋게 쓰기 쉬운 때다. 즐겁게 쓰되 계획은 지키자.
- [ ] **초등 친구**: 친구들과 신나게 노는 날이 많다. 함께 놀던 친구가 소외되지 않게 챙기자.
- [ ] **중등 친구**: 친구들 사이에서 분위기 메이커가 된다. 들뜬 마음에 한 말이 누군가에게 상처가 되지 않게 살피자.
- [ ] **고등 친구**: 함께 웃고 힘이 되는 친구들이 있다. 바쁜 시기에도 즐거운 추억을 만든다.
- [ ] **그림 속 상징**: 흰 말 위의 아이: 꾸밈없는 기쁨과 순수함
- [ ] **그림 속 상징**: 해바라기: 밝은 쪽을 향하는 마음
- [ ] **지금 해 볼 일**: 오늘 고마운 사람에게 밝게 인사하거나 짧게 고맙다고 말해 보세요.

## 심판 (Judgement)
- [ ] **친구 관계**: 관계를 이어 갈지 정리할지 결정하게 된다. 연락이 끊겼던 친구에게서 소식이 올 수 있다.
- [ ] **새학기**: 지난 학기에 쌓아 둔 것이 새 학기에 결과로 돌아온다.
- [ ] **진로**: 그동안의 노력을 바탕으로 중요한 결정을 내린다. 마지막 기회를 놓치지 말아야 한다.
- [ ] **가족**: 오래 미뤄 온 가족 문제에 결론이 난다. 멀어졌던 가족과 다시 가까워질 수 있다.
- [ ] **짝사랑·고백**: 마음을 전할지 결정할 때가 온다. 예전에 놓친 기회가 다시 찾아올 수 있다.
- [ ] **외모·자신감**: 예전에 좋았던 스타일을 다시 시도해 보기 좋다. 내 모습을 새로운 눈으로 다시 보게 된다.
- [ ] **요즘 내 마음**: 지난 일을 돌아보며 마음을 정리한다. 지난 실수보다 거기서 배운 것에 집중하자.

## 완드 7 (Seven of Wands)

- [ ] **그림 속 상징**: 탁 트인 들판: 막힘없는 흐름
- [ ] **지금 해 볼 일**: 미뤄 둔 답장이나 연락을 오늘 바로 처리해 보세요.

- [ ] **그림 속 상징**: 뒤에 늘어선 막대들: 지켜 온 것들

- [ ] **그림 속 상징**: 구름에서 내미는 잔: 보지 못한 새 기회

- [ ] **중등 친구**: 친구에게 실망하거나 무리에서 상처를 받았다. 곁에 남아 있는 친구에게 기대자.
- [ ] **고등 친구**: 멀어진 친구 때문에 아쉽다. 지금 곁에 있는 친구도 소중하다.
- [ ] **그림 속 상징**: 쓰러진 잔 세 개: 잃어버린 것에 대한 슬픔
- [ ] **그림 속 상징**: 뒤에 서 있는 잔 두 개: 아직 남아 있는 것
- [ ] **지금 해 볼 일**: 아쉬운 일 대신 아직 남아 있는 좋은 것 하나를 떠올려 보세요.

## 컵 6 (Six of Cups)
- [ ] **취업**: 예전에 인연이 있던 곳이나 아는 사람을 통한 기회가 생긴다.
- [ ] **성적**: 성적이 좋았던 때를 떠올리며 기초를 다시 다지면 도움이 된다.
- [ ] **친구 관계**: 옛 친구가 떠오르거나 다시 연락이 닿는다. 편하고 따뜻한 사이다.
- [ ] **새학기**: 예전 반을 떠올리며 지금과 비교한다. 아는 친구가 있으면 적응이 쉽다.
- [ ] **진로**: 어릴 때 좋아하던 일에서 진로의 실마리를 찾는다.
- [ ] **가족**: 가족과 지난 추억을 나누며 정이 깊어진다. 편안하고 소박한 분위기다.
- [ ] **짝사랑·고백**: 예전부터 알던 사람에게 마음이 간다. 편하고 따뜻한 감정이 자란다.
- [ ] **외모·자신감**: 예전에 즐겨 하던 스타일이 다시 잘 어울린다. 편안한 모습이 매력이다.
- [ ] **요즘 내 마음**: 좋았던 추억이 떠오르며 마음이 따뜻해진다. 옛 사진이 위로가 된다.
- [ ] **용돈·돈 관리**: 어릴 적 받았던 용돈이나 선물처럼 소박한 기쁨이 있다. 작은 것에 만족하면 돈이 남는다.
- [ ] **초등 친구**: 유치원이나 예전 반 친구와 다시 만난다. 편하게 함께 논다.
- [ ] **중등 친구**: 초등학교 때 친구와 다시 연락이 닿는다. 편한 친구가 큰 힘이 된다.
- [ ] **고등 친구**: 오래된 친구와의 추억이 힘이 된다. 옛 친구에게 안부를 전해 보자.
- [ ] **그림 속 상징**: 꽃이 든 잔을 건네는 아이: 순수한 마음을 주고받음
- [ ] **그림 속 상징**: 오래된 마을: 그리운 시절
- [ ] **지금 해 볼 일**: 오랜만에 옛 친구나 가족에게 안부 메시지를 보내 보세요.

## 컵 7 (Seven of Cups)
- [ ] **취업**: 가고 싶은 곳이 너무 많거나 너무 멀다. 현실적인 목표를 골라야 한다.
- [ ] **성적**: 계획만 많고 집중이 흩어진다. 하나에 몰두해야 한다.
- [ ] **친구 관계**: 친구에게 바라는 것이 많아 마음이 혼란스럽다. 좋은 면과 싫은 면이 함께 떠오른다.
- [ ] **새학기**: 새 학기에 대한 상상은 크지만 현실과 다를 수 있다. 할 일을 하나씩 정해야 한다.
- [ ] **진로**: 하고 싶은 것이 너무 많거나 너무 멀다. 현실적인 목표 하나를 골라야 한다.
- [ ] **가족**: 가족에게 기대하는 것과 실제가 달라 혼란스럽다.
- [ ] **짝사랑·고백**: 상대에 대한 상상이 커져 혼란스럽다. 상상과 실제를 구분하자.
- [ ] **외모·자신감**: 이것저것 다 해 보고 싶어 고르기 어렵다. 하나씩 시도해 보면 맞는 것이 보인다.
- [ ] **요즘 내 마음**: 생각이 여러 갈래로 흩어져 마음이 어지럽다. 하나만 골라 집중해 보자.
- [ ] **용돈·돈 관리**: 사고 싶은 것이 너무 많다. 진짜 필요한 것 하나만 고르자.
- [ ] **초등 친구**: 친구가 많아 누구와 놀지 고민된다. 오늘 함께 놀 친구 한 명을 정하자.
- [ ] **중등 친구**: 친구에게 기대가 많아 마음이 복잡하다. 친구도 완벽하지 않다는 것을 받아들이자.
- [ ] **고등 친구**: 여러 진로와 관계 사이에서 혼란스럽다. 진짜 중요한 것을 정하면 정리된다.
- [ ] **그림 속 상징**: 구름 위 일곱 잔: 저마다 다른 꿈과 유혹
- [ ] **그림 속 상징**: 잔 속의 성과 보석: 아직 현실이 아닌 바람
- [ ] **지금 해 볼 일**: 하고 싶은 것 중 지금 할 수 있는 것 하나만 골라 시작해 보세요.

## 컵 8 (Eight of Cups)
- [ ] **취업**: 지금 자리를 떠나 다른 길을 찾는다. 미련보다 판단을 따른다.
- [ ] **성적**: 붙잡고 있던 방법을 내려놓고 새 방식을 찾을 때다.
- [ ] **친구 관계**: 미련이 남아도 맞지 않는 관계에서 떠나기로 한다.
- [ ] **새학기**: 익숙했던 무리를 뒤로하고 새 관계를 찾아 나선다.
- [ ] **진로**: 지금까지의 방향을 내려놓고 다른 길을 찾는다. 마음보다 판단을 따른다.
- [ ] **가족**: 가족과 거리를 두고 내 길을 가려 한다. 독립하고 싶은 마음이 생긴다.
- [ ] **짝사랑·고백**: 마음이 이어지지 않아 정리하기로 한다. 떠나는 것도 나를 아끼는 선택이다.
- [ ] **외모·자신감**: 예전 모습을 벗어나 새로운 나를 찾고 싶다. 천천히 바꿔 나가자.
- [ ] **요즘 내 마음**: 더 이상 맞지 않는 것을 내려놓으려 한다. 아쉽지만 더 나은 쪽을 향하는 중이다.
- [ ] **용돈·돈 관리**: 쓸모없는 지출을 그만두기로 한다. 끊는 순간 돈이 남기 시작한다.
- [ ] **초등 친구**: 나랑 맞지 않는 놀이 친구 대신 다른 친구와 놀게 된다. 괜찮은 일이다.
- [ ] **중등 친구**: 맞지 않는 무리에서 나오기로 한다. 혼자인 시간이 있어도 곧 맞는 친구를 만난다.
- [ ] **고등 친구**: 오래 이어 온 관계라도 맞지 않으면 거리를 둔다. 나에게 맞는 사람을 찾는 과정이다.
- [ ] **그림 속 상징**: 쌓인 잔을 두고 떠나는 사람: 미련을 내려놓음
- [ ] **그림 속 상징**: 달빛 아래 산길: 더 깊은 것을 찾아 나섬
- [ ] **지금 해 볼 일**: 더 이상 나에게 맞지 않는 것 하나를 내려놓아 보세요.

## 컵 9 (Nine of Cups)
- [ ] **취업**: 내가 바라던 조건을 얻는다. 만족스러운 결과다.
- [ ] **성적**: 스스로 세운 목표에 닿아 만족한다.
- [ ] **친구 관계**: 지금 관계에 만족한다. 굳이 새 친구를 찾지 않아도 충분하다.
- [ ] **새학기**: 새 환경이 마음에 들어 만족스럽다. 나만의 편안한 자리를 찾는다.
- [ ] **진로**: 내 기준으로 원하던 방향을 얻는다. 남의 평가보다 나의 만족이 중요하다.
- [ ] **가족**: 집에서 편안하고 만족스럽다. 다만 내 기분이 먼저라 가족을 덜 살필 수 있다.
- [ ] **짝사랑·고백**: 지금 마음에 만족한다. 굳이 서두르지 않아도 마음이 편하다.
- [ ] **외모·자신감**: 지금의 내 모습에 만족한다. 이 마음이 자신감으로 드러난다.
- [ ] **요즘 내 마음**: 원하던 일이 이뤄져 마음이 뿌듯하다. 충분히 누리자.
- [ ] **용돈·돈 관리**: 원하던 것을 살 수 있게 된다. 사고 나서도 조금 남겨 두자.
- [ ] **초등 친구**: 친구들과 노는 것이 즐겁고 만족스럽다. 내 것을 친구와 나누면 더 좋다.
- [ ] **중등 친구**: 지금 친구들로 충분히 만족한다. 새 친구가 다가오면 반갑게 맞아 주자.
- [ ] **고등 친구**: 마음 편한 친구들이 있어 든든하다. 자랑보다 함께 나누는 기쁨이 크다.
- [ ] **그림 속 상징**: 팔짱 끼고 웃는 사람: 만족과 자부심
- [ ] **그림 속 상징**: 뒤에 늘어선 아홉 잔: 이뤄진 소원
- [ ] **지금 해 볼 일**: 이뤄진 일 하나를 떠올리며 스스로에게 작은 보상을 해 보세요.

## 컵 10 (Ten of Cups)
- [ ] **취업**: 분위기 좋은 곳에 안정적으로 자리 잡는다.
- [ ] **성적**: 크게 오르지는 않아도 안정적인 성적을 유지한다.
- [ ] **친구 관계**: 친구들과 화목하게 어울린다. 무리 안에서 평화롭고 안정적이다.
- [ ] **새학기**: 반 분위기가 화목해 안정적으로 자리 잡는다.
- [ ] **진로**: 함께하는 사람들과 행복할 수 있는 길을 찾는다. 안정적인 방향이 좋다.
- [ ] **가족**: 가족이 함께 화목하다. 집안에 평화와 안정이 있다.
- [ ] **짝사랑·고백**: 편안하고 따뜻한 관계를 꿈꾼다. 서로를 아끼는 마음이 잘 맞는다.
- [ ] **외모·자신감**: 가족이나 친구가 내 모습을 좋아해 준다. 편안할 때 가장 나답다.
- [ ] **요즘 내 마음**: 가족과 친구에게 둘러싸여 마음이 편안하다. 소중한 사람들과 시간을 보내자.
- [ ] **용돈·돈 관리**: 가족과 함께 계획하며 쓰면 좋다. 가족 선물을 위해 모으는 것도 좋다.
- [ ] **초등 친구**: 반 친구들과 사이좋게 지낸다. 모두 함께하는 놀이가 즐겁다.
- [ ] **중등 친구**: 무리 안에서 평화롭고 편안하다. 서로를 챙기는 좋은 친구들이다.
- [ ] **고등 친구**: 서로 응원하는 친구들과 함께 지낸다. 힘든 시기도 함께라 견딜 만하다.
- [ ] **그림 속 상징**: 하늘의 무지개 잔: 함께 누리는 행복
- [ ] **그림 속 상징**: 춤추는 아이들: 평화롭고 따뜻한 일상
- [ ] **지금 해 볼 일**: 가족이나 친구와 함께 밥을 먹으며 오늘 있었던 일을 나눠 보세요.

- [ ] **고등 친구**: 조용히 마음을 나누는 친구가 생긴다. 작은 쪽지나 메시지가 마음을 전한다.
- [ ] **그림 속 상징**: 잔 속에서 고개 내민 물고기: 뜻밖의 감정과 상상
- [ ] **그림 속 상징**: 바다 앞에 선 소년: 풍부한 감성
- [ ] **지금 해 볼 일**: 쑥스러워도 짧은 인사 한마디를 먼저 건네 보세요.

## 컵 나이트 (Knight of Cups)
- [ ] **연애 흐름**: 낭만적인 제안이나 고백이 다가온다.
- [ ] **상대의 속마음**: 마음을 티 내며 다가오지만 표현 방식이 서툴다.
- [ ] **취업**: 마음에 드는 제안이 온다. 조건은 현실적으로 따져 봐야 한다.
- [ ] **성적**: 기분에 따라 공부 의욕이 오르내린다.
- [ ] **발표·사업**: 이상적인 제안을 내놓지만 현실성 검토가 필요하다.
- [ ] **재물**: 기분 따라 쓰는 돈을 조심해야 한다.
- [ ] **이동·여행**: 분위기 좋은 여행 제안이 들어온다.
- [ ] **친구 관계**: 친구가 다정한 제안이나 화해의 손길을 내민다.
- [ ] **새학기**: 마음 맞는 친구에게 함께하자는 제안을 받는다.
- [ ] **진로**: 마음에 드는 길을 제안받는다. 낭만만큼 현실 조건도 살펴야 한다.
- [ ] **가족**: 가족 사이에 다정한 말과 마음이 오간다. 화해의 기회가 생긴다.
- [ ] **짝사랑·고백**: 다정한 고백이나 제안이 오갈 수 있다. 진심을 담아 천천히 다가가자.

- [ ] **요즘 내 마음**: 마음이 말랑해지고 다정해진다. 좋아하는 사람에게 마음을 표현하고 싶다.

## 소드 3 (Three of Swords)

- [ ] **그림 속 상징**: 벽에 걸린 세 칼: 잠시 내려놓은 고민

## 소드 5 (Five of Swords)

- [ ] **친구 관계**: 말다툼에서 이겨도 친구를 잃을 수 있다. 생각 차이가 분명히 드러난다.

- [ ] **진로**: 경쟁에서 앞서도 개운하지 않다. 남과 부딪치는 방식은 조심해야 한다.
- [ ] **가족**: 가족과 언쟁이 생긴다. 이겨도 서로 마음이 상한다.
- [ ] **짝사랑·고백**: 자존심 싸움으로 마음이 상할 수 있다. 이기는 것보다 마음을 지키는 것이 중요하다.

## 소드 6 (Six of Swords)

- [ ] **지금 해 볼 일**: 나를 편하게 해 주는 장소나 사람 곁에서 시간을 보내 보세요.

## 소드 7 (Seven of Swords)

- [ ] **그림 속 상징**: 남겨 둔 두 칼: 다 챙기지 못한 것
- [ ] **지금 해 볼 일**: 숨기고 있던 작은 일이 있다면 솔직하게 말해 보세요.

## 소드 8 (Eight of Swords)

- [ ] **성적**: 한 가지 방식만 고집해 막혀 있다.
- [ ] **친구 관계**: 혼자 생각에 갇혀 친구를 오해한다. 직접 물어보면 풀린다.
- [ ] **새학기**: 걱정과 생각에 갇혀 먼저 움직이지 못한다. 생각보다 상황은 열려 있다.

- [ ] **용돈·돈 관리**: 돈이 없어 아무것도 못 한다고 느낀다. 돈 들지 않는 즐거움도 많다.

- [ ] **친구 관계**: 친구 관계에 대한 걱정으로 잠을 설친다. 나쁜 쪽으로 짐작하지 않는 것이 좋다.

- [ ] **용돈·돈 관리**: 돈 걱정에 마음이 무겁다. 실제 숫자를 적어 보면 생각보다 괜찮을 수 있다.

- [ ] **고등 친구**: 관계와 공부 걱정이 겹쳐 잠을 못 이룬다. 걱정을 적고 잠은 꼭 챙기자.
- [ ] **그림 속 상징**: 얼굴을 감싼 사람: 밤의 걱정과 불안
- [ ] **그림 속 상징**: 어둠 속 아홉 칼: 마음이 만든 두려움
- [ ] **지금 해 볼 일**: 자기 전 걱정을 종이에 적어 두고, 내일 할 일 하나만 정해 보세요.

## 소드 10 (Ten of Swords)

- [ ] **지금 해 볼 일**: 지금 힘들다면 믿을 만한 사람에게 오늘 연락해 보세요. 혼자 버티지 않아도 됩니다.

- [ ] **성적**: 논리적으로 정리하는 힘이 강해 성적이 좋다.

- [ ] **그림 속 상징**: 파도 위의 배: 오르내리는 상황
- [ ] **지금 해 볼 일**: 이번 주 일정표를 짜고 겹치는 일 하나를 조정해 보세요.

- [ ] **그림 속 상징**: 설계도를 든 두 사람: 함께 의견을 모음
- [ ] **지금 해 볼 일**: 혼자 하던 일을 누군가와 함께 해 보세요.

## 펜타클 4 (Four of Pentacles)
- [ ] **취업**: 가진 것을 놓기 싫어 새 도전을 망설인다.
- [ ] **성적**: 익숙한 방식만 고집해 성적이 제자리에 머문다.
- [ ] **친구 관계**: 지금 친구를 놓치기 싫어 붙잡는다. 다른 친구와 어울리는 것을 꺼린다.

- [ ] **진로**: 안정된 길만 붙잡고 새 도전을 망설인다.
- [ ] **가족**: 가진 것을 지키려 서로 아끼고 조심한다. 변화를 꺼리는 분위기다.
- [ ] **짝사랑·고백**: 상대를 놓치기 싫어 꼭 붙잡고 싶다. 붙잡을수록 상대가 답답할 수 있다.
- [ ] **외모·자신감**: 익숙한 스타일만 고집한다. 가끔은 새로운 시도도 괜찮다.

- [ ] **초등 친구**: 단짝이 다른 친구와 놀면 서운하다. 같이 놀자고 하면 친구가 더 늘어난다.

- [ ] **고등 친구**: 익숙한 친구들만 고집한다. 새 사람에게도 마음을 조금 열어 보자.
- [ ] **그림 속 상징**: 펜타클을 끌어안은 사람: 지키려는 마음
- [ ] **그림 속 상징**: 발밑과 머리 위의 펜타클: 꽉 쥐어 움직이지 못함
- [ ] **지금 해 볼 일**: 꽉 쥐고 있던 것 하나를 나누거나 조금 풀어 보세요.

## 펜타클 5 (Five of Pentacles)

- [ ] **취업**: 조건이 좋지 않다. 기대보다 못한 곳일 수 있다.
- [ ] **성적**: 여건이 어려워 성적이 오르기 힘들다.
- [ ] **친구 관계**: 함께 있어도 불편하고 소외감을 느낀다. 도움을 청하면 손 내밀 사람이 있다.
- [ ] **새학기**: 새 반에서 소외감을 느낄 수 있다. 먼저 도움을 청하는 용기가 필요하다.
- [ ] **진로**: 조건이 부족해 원하는 길이 멀게 느껴진다. 도움받을 곳을 찾아야 한다.
- [ ] **가족**: 집안 사정이나 분위기가 어렵다. 함께 있어도 서로 힘들다.
- [ ] **짝사랑·고백**: 외롭고 자신이 없어 마음을 꺼내기 어렵다. 나를 따뜻하게 대해 주는 사람이 가까이 있다.
- [ ] **외모·자신감**: 내 모습이 초라하게 느껴진다. 그 느낌은 지나가는 것이고 나는 충분히 괜찮다.
- [ ] **요즘 내 마음**: 외롭고 힘든 마음이 크다. 도움을 청하면 손을 내밀 사람이 있으니 꼭 이야기하자.

- [ ] **초등 친구**: 친구들 사이에서 혼자인 것 같아 슬프다. 꼭 선생님이나 부모님께 이야기하자.
- [ ] **중등 친구**: 무리에서 소외된 느낌이 든다. 혼자 견디지 말고 믿는 어른이나 상담 선생님에게 도움을 청하자.

- [ ] **그림 속 상징**: 불 켜진 창문: 바로 곁에 있는 도움

## 펜타클 6 (Six of Pentacles)
- [ ] **상대의 속마음**: 호의를 베풀지만 속으로는 따져 보고 있다.

- [ ] **요즘 내 마음**: 도움을 주고받으며 마음이 따뜻해진다. 받는 것도 부끄러운 일이 아니다.
- [ ] **용돈·돈 관리**: 친구에게 빌려주거나 빌릴 일이 생긴다. 언제 갚을지 분명히 하자.
- [ ] **초등 친구**: 친구와 장난감이나 간식을 나눈다. 빌린 것은 꼭 돌려주자.
- [ ] **중등 친구**: 친구를 돕거나 도움을 받는다. 주고받는 것이 한쪽으로 치우치지 않게 하자.
- [ ] **고등 친구**: 공부 자료나 정보를 나누며 가까워진다. 서로 돕는 관계가 힘이 된다.

- [ ] **지금 해 볼 일**: 도움이 필요한 사람에게 작은 도움을 주거나, 필요한 도움을 요청해 보세요.

## 펜타클 7 (Seven of Pentacles)
- [ ] **상대의 속마음**: 지금 관계에 아쉬움이 있어 더 나아지기를 바란다.
- [ ] **취업**: 결과는 있지만 만족스럽지 않다. 더 나은 곳을 고민한다.
- [ ] **성적**: 성적은 나왔지만 아쉽다. 공부 방법을 돌아보면 더 오른다.
- [ ] **친구 관계**: 지금 관계가 아직 아쉽다. 더 가까워지려면 노력이 필요하다.
- [ ] **새학기**: 생각만큼 잘 적응하지 못해 아쉽다. 무엇을 바꿀지 돌아보는 시기다.
- [ ] **진로**: 지금까지의 노력이 만족스럽지 않다. 방향을 다시 점검한다.
- [ ] **가족**: 가족을 위해 애쓴 만큼 돌아오지 않아 아쉽다.
- [ ] **짝사랑·고백**: 마음을 키워 왔지만 아직 결과가 없어 아쉽다. 조금 더 지켜보며 노력해 보자.
- [ ] **외모·자신감**: 노력해 왔지만 변화가 더디게 느껴진다. 꾸준히 하면 결과가 따라온다.
- [ ] **요즘 내 마음**: 열심히 했는데 결과가 아쉬워 마음이 복잡하다. 지금까지 해 온 것도 충분히 의미 있다.
- [ ] **용돈·돈 관리**: 모은 돈을 보며 더 모을지 쓸지 고민한다. 목표를 다시 점검해 보자.
- [ ] **초등 친구**: 친구와 더 친해지고 싶은데 잘 안 된다. 같이 노는 시간을 조금씩 늘려 보자.
- [ ] **중등 친구**: 친구 관계가 아직 아쉽다. 조급해하지 말고 꾸준히 다가가자.
- [ ] **고등 친구**: 노력에 비해 관계가 더디게 가까워진다. 시간이 해결해 줄 부분도 있다.
- [ ] **그림 속 상징**: 괭이에 기대어 바라보는 농부: 결과를 기다리며 돌아봄
- [ ] **그림 속 상징**: 덤불에 열린 펜타클: 자라나는 결실

## 펜타클 8 (Eight of Pentacles)
- [ ] **상대의 속마음**: 지금은 자기 일에 빠져 있어 감정 표현이 적다.
- [ ] **취업**: 성실하게 쌓아 온 실력이 인정받는다.
- [ ] **성적**: 꾸준히 반복하는 공부가 실력을 만든다.
- [ ] **친구 관계**: 공부나 일에 몰두해 친구에게 신경 쓸 겨를이 없다.

- [ ] **진로**: 꾸준한 연습과 반복으로 실력을 쌓는다. 기술이나 전문성이 필요한 길과 잘 맞는다.
- [ ] **가족**: 각자 일에 몰두해 대화가 적다. 성실하게 제 몫을 한다.
- [ ] **짝사랑·고백**: 마음보다 할 일에 집중하는 시기다. 꾸준한 모습이 상대에게 믿음을 준다.

- [ ] **용돈·돈 관리**: 꾸준히 조금씩 모은다. 작은 돈도 쌓이면 크다.
- [ ] **초등 친구**: 좋아하는 것에 빠져 친구와 놀 시간이 줄어든다. 친구와 함께 하면 더 즐겁다.
- [ ] **중등 친구**: 공부나 취미에 몰두해 친구에게 소홀해진다. 짧은 연락이라도 이어 가자.

## 펜타클 9 (Nine of Pentacles)
- [ ] **상대의 속마음**: 혼자서도 충분해 관계에 크게 매달리지 않는다.
- [ ] **취업**: 쌓아 온 능력을 인정받아 좋은 결과를 얻는다.
- [ ] **성적**: 꾸준히 공들인 만큼 만족스러운 성적이 나온다.
- [ ] **친구 관계**: 혼자서도 충분해 새 친구를 찾지 않는다. 친구가 서운해할 수 있다.
- [ ] **새학기**: 스스로 공들여 만든 생활이 안정적이다. 혼자서도 잘 지낸다.
- [ ] **진로**: 스스로 쌓아 온 능력으로 원하는 자리를 얻는다. 자립하는 길이 어울린다.
- [ ] **가족**: 집에서 여유롭고 편안하다. 가족에게 기대지 않고 스스로 해낸다.
- [ ] **짝사랑·고백**: 혼자서도 충분히 즐겁다. 서두르지 않아도 매력이 자연스럽게 전해진다.
- [ ] **외모·자신감**: 나를 위해 투자한 시간이 빛을 낸다. 품위 있고 여유로운 모습이 매력이다.
- [ ] **요즘 내 마음**: 혼자서도 마음이 넉넉하고 여유롭다. 스스로를 칭찬해 주자.
- [ ] **용돈·돈 관리**: 아껴 모은 덕분에 여유가 생긴다. 나를 위한 의미 있는 곳에 써 보자.
- [ ] **초등 친구**: 혼자서도 잘 논다. 친구가 함께 놀자고 하면 반갑게 응해 주자.
- [ ] **중등 친구**: 혼자서도 충분해 새 친구를 찾지 않는다. 친구가 서운해하지 않게 가끔 먼저 연락하자.
- [ ] **고등 친구**: 스스로 해 나가는 힘이 있다. 친구에게 도움을 주는 여유도 생긴다.
- [ ] **그림 속 상징**: 포도밭의 여인: 스스로 일군 풍요
- [ ] **그림 속 상징**: 손 위의 매: 잘 다스린 마음
- [ ] **지금 해 볼 일**: 혼자서 즐길 수 있는 좋은 시간을 오늘 한 번 가져 보세요.

## 펜타클 10 (Ten of Pentacles)
- [ ] **상대의 속마음**: 내 마음을 고맙게 받기보다 당연하게 여길 수 있다.
- [ ] **취업**: 규모 있는 곳과 연결된다. 집안이나 주변의 도움이 작용할 수 있다.
- [ ] **성적**: 여건은 넉넉하지만 결국 스스로의 노력이 결과를 가른다.
- [ ] **친구 관계**: 오래된 친구 무리 안에서 안정적이다. 그러나 속마음까지 전해지지는 않는다.
- [ ] **새학기**: 큰 학교나 넓은 무리에 속하게 된다. 아는 사람이나 인맥이 도움이 된다.
- [ ] **진로**: 집안이나 주변의 도움이 진로에 작용한다. 규모 있고 안정적인 길과 연결된다.
- [ ] **가족**: 집안이 안정되어 있지만 서로의 마음은 잘 전해지지 않는다.
- [ ] **짝사랑·고백**: 오래 알고 지낸 사이에서 마음이 자란다. 다만 속마음까지는 아직 전해지지 않았다.
- [ ] **외모·자신감**: 가족에게서 물려받은 나만의 장점이 있다. 그 장점을 살리면 좋다.
- [ ] **요즘 내 마음**: 가족과 익숙한 환경에서 안정감을 느낀다. 그래도 속마음은 표현해야 전해진다.
- [ ] **용돈·돈 관리**: 가족과 함께 돈 계획을 세우면 좋다. 큰 목표는 가족과 상의하자.
- [ ] **초등 친구**: 오래된 친구들과 편하게 논다. 새로 온 친구도 함께 끼워 주자.
- [ ] **중등 친구**: 익숙한 친구 무리 안에서 안정적이다. 속마음을 나누면 더 가까워진다.
- [ ] **고등 친구**: 오래된 친구 무리가 든든하다. 서로의 진짜 고민도 나눠 보자.
- [ ] **그림 속 상징**: 아치 아래의 가족: 대대로 이어지는 안정
- [ ] **그림 속 상징**: 개를 쓰다듬는 노인: 오래 지켜 온 것
- [ ] **지금 해 볼 일**: 가족에게 요즘 내 생각이나 고민을 하나 이야기해 보세요.

## 펜타클 페이지 (Page of Pentacles)

## 펜타클 나이트 (Knight of Pentacles)

## 펜타클 퀸 (Queen of Pentacles)

## 펜타클 킹 (King of Pentacles)
- [ ] **연애 흐름**: 안정적이고 든든한 관계다. 감정보다 현실을 앞세운다.
- [ ] **상대의 속마음**: 효율과 실리를 따지며 관계를 바라본다.
- [ ] **취업**: 탄탄한 조건의 자리를 얻는다.
- [ ] **성적**: 효율적인 방법으로 확실한 결과를 낸다.
- [ ] **발표·사업**: 효율을 따져 확실한 성과를 낸다.
- [ ] **재물**: 재물운이 탄탄하다.
- [ ] **이동·여행**: 득실을 따져 이득이 확실할 때 움직인다.
- [ ] **친구 관계**: 든든하고 믿음직한 친구다. 감정 표현보다 현실적인 도움을 준다.
- [ ] **새학기**: 안정된 기반 위에서 여유 있게 시작한다.
- [ ] **진로**: 오랜 노력 끝에 탄탄한 성과를 이룬다. 현실적이고 안정된 길이 어울린다.
- [ ] **가족**: 집안의 기반이 탄탄하다. 현실적인 면에서 가족을 든든히 받친다.
- [ ] **짝사랑·고백**: 든든하고 믿음직한 모습으로 다가간다. 말보다 행동으로 마음을 보여 준다.
- [ ] **외모·자신감**: 여유 있고 안정된 분위기가 매력이다. 좋은 것 하나를 오래 쓰는 스타일이 어울린다.
- [ ] **요즘 내 마음**: 마음이 안정되어 흔들림이 적다. 이 안정감을 주변과 나누자.
- [ ] **용돈·돈 관리**: 계획적으로 관리해 돈이 잘 모인다. 모은 돈을 의미 있는 곳에 쓰자.
- [ ] **초등 친구**: 친구들이 믿고 따른다. 내 것을 나누면 더 사랑받는다.
- [ ] **중등 친구**: 든든한 친구로 여겨진다. 감정 표현도 조금 더 해 보자.
- [ ] **고등 친구**: 현실적인 도움을 주는 믿음직한 친구다. 따뜻한 말 한마디도 함께 건네자.
- [ ] **그림 속 상징**: 포도 무늬 옷의 왕: 노력으로 이룬 풍요
- [ ] **그림 속 상징**: 황소 머리 왕좌: 흔들리지 않는 안정
- [ ] **지금 해 볼 일**: 이번 달 쓰고 모을 돈을 계획표로 정리해 보세요.
